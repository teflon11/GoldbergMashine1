# Экспонат №7 «Будильник для хомяка»

Машина Голдберга в одном файле: **настоящая физика Matter.js**, без единой
анимированной «имитации механики». Шар катится, костяшки падают, качели
качаются, маятник бьёт по колоколу — всё двигает решатель физики.

## Запуск

Открыть `index.html` в браузере (двойным кликом). Всё, что нужно, —
Matter.js 0.20.0 с CDN.

- **▶ START** — запустить машину (пробел — тоже).
- **⟲ RESET** — вернуть экспонат в исходное состояние (клавиша `R`).

## Что происходит

11 ступеней, одна цепная реакция, финал — звон колокола и спящий хомяк,
который от этого просыпается:

| № | Ступень | Механизм |
|---|---------|----------|
| 1 | ПУСКОВОЙ МЕХАНИЗМ | пружинный толкатель разгоняет шар A |
| 2 | ДЛИННЫЙ СКАТ | шар A разгоняется по рельсу |
| 3 | ЦЕПЬ ДОМИНО | шар бьёт по верхушкам костяшек — цепочка из 9 штук |
| 4 | ПОСЛЕДНЕЕ ДОМИНО | последняя костяшка вышибает второй шар |
| 5 | ВТОРОЙ ШАР | шар катится по полке к воронке |
| 6 | ВОРОНКА | шар скользит по наклонной стенке вправо |
| 7 | КАЧЕЛИ | шар перевешивает площадку на шарнире |
| 8 | ДЛИННЫЙ ЖЁЛОБ | шар катится по змейке |
| 9 | МАЯТНИК | шар бьёт по куполу колокола |
| 10 | КОЛОКОЛ | колокол звонит и раскачивается |
| 11 | ХОМЯК ПРОСЫПАЕТСЯ | купол достаёт до спящего хомяка + салют |

## Почему машина срабатывает каждый раз

Три решения, на которых держится надёжность:

1. **Стадия подтверждается состоянием тел, а не «касанием» фиксированного
   сенсора.** Переход на следующую ступень происходит по измеримому признаку:
   координата шара, угол падения костяшки, отклонение маятника. Поэтому
   переходы не срабатывают ложно и не зависят от того, как именно упало домино.
2. **Страховка на случай застревания.** Если шар объективно стоит и не
   двигается дольше 2.6 с, на него действует физическая сила в направлении
   маршрута. Это сила по-настоящему, а не анимация: тело едет и падает так же.
3. **Геометрия подобрана измерением, а не на глаз.** Ключевые параметры
   (высота/зазор костяшек, массы шара и маятников, точки удара) найдены
   перебором: `tools/domino-lab2.mjs` и `tools/sweep.mjs` прогоняют сотни
   вариантов и печатают, сколько костяшек упало.

## Проверка

```bash
npm install
node tools/build.mjs          # собрать index.html из исходников
node tools/test.mjs 5         # 5 прогонов подряд + цикл RESET → START
node tools/browser-check.mjs  # прогон в реальном браузере + скриншоты
```

`tools/test.mjs` — главный тест: 5 независимых запусков плюс проверка, что
после `RESET` машина снова полностью отрабатывает. Ожидаемый результат:

```
OK   прогон 1: стадия 11/11 «САЛЮТ» | звон=да | хомяк=да | страховок=0 | t=12.95s
...
OK   RESET→START: первый=ок, после сброса ст.1 фаза=idle, второй=ок
```

`tools/trace.mjs` печатает траекторию шара по кадрам — им удобно ловить,
где именно механизм встал.

## Структура

```
index.html              ← итоговый самодостаточный файл (собирается)
src/parts/*.js          ← ядро физики (ЕДИНСТВЕННЫЙ источник правды)
src/uiparts/*.js        ← отрисовка сцены (ЕДИНСТВЕННЫЙ источник правды)
src/app.js              ← кнопки, игровой цикл
src/sound.js            ← звук на WebAudio (без внешних файлов)
src/index.template.html ← HTML-каркас и стили
tools/                  ← сборка и тесты
shots/                  ← скриншоты прогона в браузере (пересоздаются)
node_modules/           ← только для тестов; сам index.html их не требует
```

Промежуточных сборочных файлов нет: `tools/build.mjs` подставляет части
прямо в `index.html`, а инструменты читают те же части через
`tools/load-core.mjs`. Поэтому «разъехаться» физике и картинке негде, а
дубликатов кода в проекте тоже нет.

## Мелочи, которые стоит знать

- Физика идёт **фиксированным шагом** (1/60 с), рендер — каждый кадр.
  Благодаря этому машина отрабатывает одинаково от запуска к запуску.
- Звук синтезируется в WebAudio: колокол — пять негармонических партиал
  с затуханием, плюс аккорд на финале. Внешних аудиофайлов нет.
- Колокол в покое висит **свободно**: если бы он опирался на конец жёлоба,
  то сползал бы по нему вправо и будил хомяка сам. Поэтому рельс заканчивается
  за 26 пикселей до купола.
